# SMARTINI’s

**S**mart **M**emo **A**rtificial **R**ecording **T**ranscription **I**nitiative **N**otes **I**ntelligence **s**oftware

*A smart twist on every conversation.*

SMARTINI’s turns recordings into transcripts, readable notes and searchable
meeting memory using local AI. It combines the recognizable martini-glass shape
with voice and knowledge motifs. The name is playful; the software still operates
as the documented local transcription, reporting and retrieval workflow.

## Logo

![SMARTINI’s logo](../assets/brand/smartinis-logo.png)

- The **martini glass** establishes the name and cocktail reference.
- The **waveform in the glass** represents recorded speech and transcription.
- The **olive and connected nodes** suggest stored memories and intelligence.
- Deep navy, mint/teal and olive-gold keep the identity readable and distinctive.

The supplied PNG has a transparent background. Use it on a light surface so the
navy wordmark stays legible. Keep the full lockup proportional and leave clear
space around it. The source asset is `assets/brand/smartinis-logo.png`; it is a
raster logo with a clean vector-like appearance, not an editable vector file.

## Existing installations stay where they are

Documentation uses `~/smartinis`, `smartinis-data`, service `smartinis` and proxy
`smartinis-proxy` only for **new** generic installations. If you already deployed
using `aartins` names, keep those paths and service names. Original MINISFORUM
installations keep `~/ai-platform`, `minisforum-meetings`, existing ingestion and
monitor units, databases, environment variables, API keys and job ownership.

The Pipe title, upload card, monitor labels and Telegram report prefix now use
SMARTINI’s in this source. To adopt the renamed Pipe, edit the existing Function
and preserve its ID and Valves; creating a second Function is unnecessary. Existing
chat history is not renamed. A source rename does not migrate a running server.
